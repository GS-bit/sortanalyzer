# SortAnalyzer
A software tool to analyze performance of sorting algorithms.

Sorting is one of the most fundamental operations a computer can do. Through it, we can see the most popular or unpopular commentaries, videos and posts, the most expensive or cheapest prices, the most voluminous or lightweight files and so on. In computing, some algorithms are used to achieve this noble task, but with different complexities. The purpose of this software is to implement several sorting algorithms and compare them considering their execution time.

The sorting algorithms available in this software are the following:
- Bubble sort
- Selection sort
- Insertion sort
- Quick sort
- Merge sort
- Heap sort

After running SortAnalyser, the program will create a random list of numbers to sort, testing all the algorithms. The user is given the possibility to set the size of the list, as well as if he/she wants to sort a random list or an already sorted (reversed or not) list.

## ⬇️ How to install SortAnalyzer:

Simply clone this repository:

```git clone https://github.com/GS-bit/sortanalyzer.git```

Then go to sortanalyzer folder:

```cd sortanalyzer/```

and run the following command:

```pipx install .```

This will start the installation process. Make sure you have pipx installed on your system. Refer to your operating system's documentation for instructions on how to install pipx.

So, you can access the program by running:

```sortanalyzer```

If you desire to uninstall sortanalyzer, run this command:

```pipx uninstall sortanalyzer```
