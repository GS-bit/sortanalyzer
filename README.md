# SortAnalyzer
A software tool to analyze performance of sort algorithms.

Sorting is one of the most fundamental operations a computer can do. Through it, we can see the most popular or unpopular commentaries, videos and posts, the most expensive or cheapest prices, the most voluminous or lightweight files and so on. In computing, some algorithms are used to achieve this noble task, but with different complexities. The purpose of this software is to implement several sorting algorithms and compare them considering their execution time.

The sorting algorithms available in this software are the following:
- Bubble sort
- Selection sort
- Insertion sort
- Quick sort
- Merge sort

After running SortAnalyser, the program will create a random list of numbers to sort, testing all the algorithms. The user is given the possibility to set the size of the list.

## ⬇️ How to install SortAnalyzer:

Simply clone this repository:

```git clone https://github.com/GS-bit/sortanalyzer.git```

Then go to sortanalyzer folder:

```cd sortanalyzer/```

and run it with:

```python3 main.py```
